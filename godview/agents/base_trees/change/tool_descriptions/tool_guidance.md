# Change Court Agent — Tool Descriptions & Guidance (c4)

- `git.list_commits`: List recent commits on the active branch within the incident lookback window.
- `git.get_commit`: Inspect diff hunks and touched files for a specific commit SHA.
- `git.get_file_contents`: Read source or configuration files at a specific ref.
- `obs.query_logs_scoped`: Correlate deployment revision tags in logs with commit timestamps.
